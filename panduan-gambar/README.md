# Gambar ilustrasi prosedur

Taruh screenshot di folder ini (format **PNG**, nama persis seperti di bawah). Gambar langsung muncul di
halaman detail prosedur (tombol "Lihat detail"); gambar yang belum ada dilewati otomatis.

Folder ini sengaja **bukan** `public/`: gambar hanya bisa dibuka karyawan yang sudah login.
Pakai data contoh; jangan tampilkan nomor rekening, nominal asli, atau data pribadi.
